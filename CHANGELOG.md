# Changelog

Todas as mudanças notáveis deste repositório ficam registradas aqui. O formato segue o [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e cada skill segue o [Versionamento Semântico](https://semver.org/lang/pt-BR/) de forma independente.

Cada versão é identificada como `<skill>@<versão>`, o mesmo nome da tag e da release no GitHub. Mudanças que não pertencem a uma skill ficam em `[Unreleased]` até entrarem em uma versão ou serem registradas como mudança do repositório.
