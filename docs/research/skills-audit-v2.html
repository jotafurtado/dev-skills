After — pick one, and mean it
Option A — make the second adapter real

Define a check the agent can actually run, and add an eval that drives the fallback path. Two adapters, both exercised.

Option B — collapse the seam

Fold the two unique fallback directives into SKILL.md, delete both reference modules, and state the pairing as a documented install contract rather than a runtime branch.

A repo with an English CHANGELOG.md and no other convention: :22 sends the commit to pt-BR, :158 sends the entry to English. Both rules are satisfied and the output is bilingual — with no clause telling the agent that is expected.
